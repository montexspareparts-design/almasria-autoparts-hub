## 2. المطلوب منك (على جهاز فيه Android Studio + JDK 17)

```bash
bun install --frozen-lockfile
bun run build
bunx cap sync android
cd android && ./gradlew bundleRelease
```
الناتج: `android/app/build/outputs/bundle/release/app-release.aab`

خطوات التوقيع (keystore + `keystore.properties` + `signingConfigs`) مشروحة بالتفصيل في `android/RELEASE.md`.

## 4. Data safety (إعلان البيانات)

- الاسم والبريد والموبايل → لإنشاء الحساب وتنفيذ الطلب.
- العنوان → للشحن.
- الكاميرا والصور → تصوير الشاسيه ورفع صور القطع (اختياري).
- سجل الشراء → لعرض الطلبات السابقة.
- البيانات مشفّرة أثناء النقل، والمستخدم يقدر يطلب حذف حسابه من داخل التطبيق.

## 5. لقطات الشاشة المطلوبة (4 على الأقل، 9:16)

1. الصفحة الرئيسية للتطبيق.
2. صفحة تفاصيل منتج (سعر + رصيد).
3. السلة مع شريط الشحن المجاني وكود الخصم.
4. صفحة الدفع أو تتبع الطلب.
