# تطبيق جملة الزيوت — بناء native حقيقي من الصفر

## الحالة دلوقتي
النسخة الحالية على `/oils` نسخة أولية، وبتستعير سلوك وأدوات من الموقع. الخطة دي تعيد بناءها كتطبيق موبايل مستقل بالكامل: كود خاص بيه، حالة خاصة بيه، وإحساس تفاعل يشبه التطبيقات الأصلية مش صفحة ويب.

## حساب المعاينة (جاهز دلوقتي)
- البريد: `demo.oils@almasriaautoparts.com`
- كلمة المرور: `OilsDemo#2026`
- الشريحة: جملة (Tier 1) — حد ائتمان 50,000 ج — الحساب مفعّل.

## 1) مبادئ التصميم اللي بتخلي التطبيق يبان "فخم ونزيه"

**أ. الفخامة = ضبط، مش زخرفة.**
لون أساسي واحد + لون تمييز واحد + تدرّجات رمادية دقيقة. مساحات فاضية كبيرة، حواف موحّدة (20px)، ظلال ناعمة جدًا بدل الحدود القوية.

**ب. الأرقام هي البطل.**
ده تطبيق تجارة جملة: السعر، الكمية، الرصيد، الحد الائتماني. خط أرقام عريض بعرض ثابت (tabular) وحجم أكبر من النص المحيط، والتمييز اللوني للسعر النهائي فقط.

**ج. النزاهة = وضوح مالي مطلق.**
- إظهار السعر قبل الخصم وبعده وسبب الخصم صراحة ("شريحة جملة" / "خصم كمية 12+").
- إجمالي حي في كل شاشة بدون مفاجآت في آخر خطوة (شحن، حد أدنى، ائتمان متاح).
- حالة المخزون حقيقية من الفيصل مع وقت آخر تحديث ظاهر.
- زر واحد واضح لكل شاشة، بدون لغة بيع ضاغطة.

**د. الحركة تشرح، ما تستعرضش.**
انتقالات 180–260ms بمنحنى spring واحد، عناصر بتدخل من الاتجاه اللي جت منه، ارتداد خفيف عند الإضافة للسلة، واهتزاز لمسي (haptic) عند كل فعل مالي.

**هـ. إحساس native حقيقي.**
- تنقّل Stack/Tabs بحالة مستقلة لكل تبويب (كل تبويب بيفتكر مكانه).
- Bottom sheets بدل النوافذ المنبثقة، وسحب للإغلاق.
- Skeletons فورية بدل سبينر، وتحديث متفائل (السعر/الكمية تتحرك قبل رد السيرفر).
- عمل بدون إنترنت: آخر كتالوج وآخر كشف حساب محفوظين محليًا.
- احترام آمن للحواف (safe areas) وشريط حالة داكن ولمسات 44px كحد أدنى.

## 2) المعمار — كود خاص بالتطبيق

```text
src/apps/oils/
  design/      tokens.ts · motion.ts · typography.ts   (نظام منفصل تمامًا)
  ui/          Sheet · Stepper · PriceBlock · Skeleton · Toast · Segmented · Tabs
  nav/         OilsNavigator  (Stack لكل تبويب + حفظ الحالة + انتقالات)
  data/        عميل بيانات خاص: كاش محلي + offline + تحديث متفائل
  screens/     Home · Catalog · Product · QuickOrder · Cart · Checkout · Account · Orders
  state/       oilsStore (سلة/جلسة/تفضيلات التاجر) مستقل عن سلة الموقع
```

قواعد صارمة: صفر استيراد من `src/components/*` أو `src/index.css`، وصفر ظهور لأي عنصر عائم من الموقع داخل `/oils` (تم تطبيقه).

## 3) الشاشات بالتفصيل
1. **الافتتاح والدخول** — شاشة بدء بحركة شعار، دخول ببريد/باسورد + حفظ الجلسة، وحالة "قيد الاعتماد" واضحة.
2. **الرئيسية** — بطاقة ائتمان حيّة (متاح/مستخدم)، إعادة آخر طلبية بضغطة، عروض الجملة، والأصناف الأكثر تكرارًا لهذا التاجر تحديدًا.
3. **الكتالوج** — بحث فوري بالكود/البارت نمبر/الاسم، فلاتر كـ bottom sheet، والعرض الثلاثي الإجباري (كود الصنف + بارت نمبر + اسم الصنف)، وسعر الشريحة مع الوفر.
4. **صفحة الصنف** — شرائح الكمية كجدول واضح (1+ / كرتونة / درم)، البدائل، والتوفر.
5. **الطلب السريع** — إدخال كود + كمية سطرًا بسطر بلوحة أرقام، إجمالي حي، ولصق قائمة كاملة دفعة واحدة.
6. **السلة والدفع** — ملخص مالي كامل قبل التأكيد، خيار الائتمان للتجار المؤهلين فقط، والدفع قبل الطلب كما هو.
7. **الطلبات** — خط زمني للحالة مع رقم ORD الظاهر ومزامنة الفيصل.
8. **حسابي** — كشف حساب، فواتير، نقاط ولاء، تفضيلات وإشعارات.

## 4) خارج النطاق الآن
تغليف متجر منفصل (appId/أيقونة)، وسكانر الباركود، وتصدير PDF — بعد اعتماد النسخة.

## 5) التحقق
اختبار كل شاشة على مقاس 430×932 بحساب المعاينة، مع قياس: صفر أخطاء كونسول، ظهور أول محتوى أقل من ثانية، وسلوك سليم بدون إنترنت.
