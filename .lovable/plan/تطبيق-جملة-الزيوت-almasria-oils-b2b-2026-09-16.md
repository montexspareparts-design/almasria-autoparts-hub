# تطبيق جملة الزيوت — ALMASRIA Oils B2B

تطبيق موبايل منفصل كليًا (بنفس مشروع الكود الحالي كمسار مستقل `/oils/*` + Capacitor) موجّه لمحلات/مراكز تغيير الزيوت وموزعي وتجار الجملة، بهوية بصرية جديدة تمامًا.

## القرارات المعتمدة من المستخدم
- تطبيق منفصل جديد كليًا بهوية بصرية جديدة.
- العملاء: محلات ومراكز تغيير زيوت + موزعين وتجار جملة.
- المميزات الإلزامية: شرائح أسعار جملة، طلب سريع وإعادة طلب، كشف حساب وائتمان، عروض/ولاء/إشعارات.

## قرار معماري مهم
إعادة استخدام نفس الـ Lovable Cloud backend الحالي (جدول `products`, `dealer_accounts`, `product_tier_prices`, `orders`, `loyalty_points`... كلها موجودة فعلاً):
- الزيوت موجودة أصلاً في الكتالوج (toyota_oils / MTX / DENSO...).
- أسعار الجملة متعددة الشرائح موجودة في `product_tier_prices` و`quantity_discounts`.
- كشف الحساب B2B موجود (erp_sales_invoices + الرصيد).
- الطلبات تسمع في الفيصل تلقائيًا عبر erp-sync-outbound الموجود.
= صفر إعادة بناء backend، وكل التركيز على تجربة وتصميم جديدين.

## الهوية البصرية الجديدة (اقتراح — قابل للتعديل قبل التنفيذ)
- اتجاه "Garage Industrial Premium": كحلي بترولي غامق `#0B1B2B` + أصفر زيت/عسلي `#F5A623` + رمادي معدني، خط عريض هندسي للأرقام (أسعار/كميات)، كروت كثيفة تشبه فاتورة مستودع.
- ثيم منفصل تمامًا عن ثيم قطع الغيار (Carbon/Gold/Red) عبر route-scoped CSS tokens.

## نطاق التنفيذ (مرحلة 1)

### ملفات جديدة
- `src/apps/oils/` — التطبيق المستقل:
  - `OilsApp.tsx` — راوتر مستقل + Providers خاصة + layout بـ bottom tabs (الرئيسية / الكتالوج / طلب سريع / حسابي).
  - `theme.css` — توكنز الثيم الجديدة (scoped على `.oils-app`).
  - `pages/OilsHome.tsx` — بانر العروض + عربيتي المختارة + أصناف مقترحة + آخر طلب لإعادة الطلب بضغطة.
  - `pages/OilsCatalog.tsx` — كتالوج الزيوت فقط (فلترة تلقائية: زيوت + فلاتر زيت)، شرائح الأسعار ظاهرة على الكارت (1+ / كرتونة / درم) مع السعر المطابق لشريحة التاجر.
  - `pages/OilsQuickOrder.tsx` — طلب سريع: إدخال كود الصنف/باركود + كمية، سطر بسطر، مع إجمالي متحدث.
  - `pages/OilsAccount.tsx` — كشف حساب وائتمان: الرصيد، حد الائتمان، آخر الفواتير، نقاط الولاء، PDF.
  - `pages/OilsLogin.tsx` — دخول تاجر (إيميل/باسورد الموجود) + طلب انضمام جديد (نفس leads flow الحالي).
  - `components/TierPriceBadge.tsx`, `components/OilProductCard.tsx`, `components/QuickOrderRow.tsx`, `components/CreditMeter.tsx`.
- `src/lib/oils/` — `useOilsCatalog.ts` (فلترة زيوت + دمج شرائح الأسعار)، `useReorder.ts` (آخر طلب → سلة)، `useCreditStatement.ts`.

### تعديلات طفيفة على الموجود
- `src/App.tsx` — إضافة mount للتطبيق على المسار `/oils` (بدون المساس بأي مسار حالي).
- `capacitor.config.ts` — لاحقًا عند تجهيز نسخة متجر منفصلة (appId مستقل) — **ليس في المرحلة 1**.

### قواعد ثابتة (لن تُمس)
- الأسعار تُخفى عن غير المسجلين؛ شرائح الجملة حسب tier التاجر؛ حد كشف الأسعار اليومي لا ينطبق هنا لأن العميل تاجر معتمد يرى شريحته مباشرة (retail bypass موجود).
- الدفع-قبل-الطلب يفضل كما هو؛ الائتمان يظهر كخيار فقط للتجار ذوي حد الائتمان.
- كل طلب يتزامن مع الفيصل برقم ORD ظاهر — بدون تغيير.
